  1. Choose a distance and read the class probability.
  2. Predict the expected makes for 5 shots.
  3. Run the simulation and compare.
  4. Explain why a simulation does not always match the prediction exactly.

Probability language

Probability: a number from 0 to 1 (or 0% to 100%).

Expected: the average result over many trials.

Random: each trial can turn out differently.

Careful!

A probability from a small class sample is an estimate, not a guarantee. More data usually makes a better estimate.
